Иерархия:

Armor (базовый класс)

  • Можно добавить в Player поле current_armor

Сложность: ⭐⭐ (простая)

Рекомендации по интеграции:

Для Armor:

  • Добавить в Player поле Armor* current_armor или int armor_defense
  • Метод Player::equip_armor(Armor& armor)
  • При получении урона учитывать защиту брони
  • Добавить в Map вектор std::vector<Armor> armors
  • Метод Map::update_armors() для проверки подбора

Для Trap:

  • Добавить в Map вектор std::vector<Trap> traps
  • Метод Map::update_traps() для проверки активации
  • При активации наносить урон игроку

Для Weapon:

  • Добавить в Player поле Weapon* current_weapon или int weapon_damage
  • Метод Player::equip_weapon(Weapon& weapon)
  • При стрельбе учитывать урон оружия
  • Добавить в Map вектор std::vector<Weapon> weapons

Для Door/Key:

  • Добавить в Player поле int keys_count
  • Добавить в Map вектор std::vector<Door> doors и std::vector<Key> keys
  • Метод Map::update_doors() и Map::update_keys()
  • При столкновении с дверью и наличии ключа - удалять дверь

Для Boss:

  • Использовать как Monster, но с большим здоровьем
  • Добавить в Map вектор std::vector<Boss> bosses или использовать существующий вектор врагов

Для Barrier:

  • Наследовать от GameObject или Wall
  • Добавить поле health_points
  • При попадании пули/гранаты - уменьшать здоровье
  • При здоровье = 0 - удалять барьер
